# 🌌 InkVortex Studio 9.0 — Generative Cinema & Subtitle Engine

![InkVortex Studio Banner](logo-inkvortex/logo-inkvortex.png)

> **InkVortex Studio 9.0** is an AI-powered editorial & video production platform integrating **Gemini 1.5 Pro**, **Mistral AI (Voxtral)**, and **FFmpeg Dynamic Subtitles** for automated 9:16 short-form video creation with 2026 high-retention typography.

---

## ✨ Features

- 🎬 **Multi-Multiverse Studio Workflow**: Seamlessly switch between Editorial, Visual, Auditory, Shorts, and Educational Rooms.
- 🎙️ **Voxtral & Gemini Music Integration**: Automated lyric generation and brasileira phonetic speech synthesis.
- ⚡ **2026 High-Retention Dynamic Subtitles**: Instant ASS subtitle generation featuring `Space Grotesk 105` typography with Micro-Pop 112% active-word karaoke pulse.
- 🛡️ **Automated Phonetic Brand Normalization**: Intelligent filter pipeline transforming ASR mispronunciations into canonical `InkVortex Brasil` branding.
- 🎨 **100% Transparent Glassmorphism UI**: Dynamic visual dashboard powered by high-definition masterpiece wallpapers.

---

## 🛠️ Tech Stack

- **Core**: Node.js, Express, HTML5, Vanilla CSS3 (Glassmorphism), JavaScript (ES6+)
- **AI Engines**: Google Gemini API, Mistral AI (Voxtral Audio Transcription API)
- **Media Processing**: FFmpeg, Advanced SubStation Alpha (.ass) Engine

---

## 🚀 Quick Start

1. **Clone the repository**:
   ```bash
   git clone https://github.com/inkvortexbrasil/VORTEX9.git
   cd VORTEX9
   ```

2. **Run the Studio**:
   Execute `iniciar-central.bat` on Windows to launch the server on `http://localhost:8787`.
